# msc-thesis

MSc thesis work: national DA-level heat-mortality vulnerability mapping (DLNM pilot),
monograph, and everything downstream. Work repo — shareable on request.

## shape
Every workstream holds four objects:
- SSOT      the thing itself, replaced each session (pipeline notebook, monograph, tracker)
- state     where it stands now, replaced each session
- ledger    log + reflexes + notes, appended, never edited
- receipts  dated dirty notebooks, added, never revised — with a README index, one line each

Session close ritual: stamp receipt → push SSOT → replace state → append ledger →
download/drag → thesis-push "log first line".

## Tree
dlnm-pilot/     the pilot. pipeline/ (SSOT notebook), notebooks/ (receipts + README),
                state, ledger. Heavy objects (tarballs, CSVs, shapefiles, fns.R) live
                on Drive at thesis/dlnm-pilot — regenerable or binary, never in git.
monograph/      same shape. Import pending.
research/       literature. paper-tracker as SSOT, syntheses as receipts, state, ledger.
                Import pending.
dissemination/  archive, not a workstream. papers/ (drafts), talks/ (TAC presentation),
                feedback/ (raw dated pieces + ledger of what was done with each).
meetings/       archive. Dated recaps and scripts.
emails/         archive. Processed/exported only — raw mail never enters git.

## Not here
Admin lives on Drive (admin-vault, Cryptomator): contracts, NDAs, ethics letters,
anything signed or identity-keyed. Signed documents never enter git — any git.
Transcripts stay local/Drive. Raw data lives in the vault; drafts carry placeholders.
